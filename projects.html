01 / MAIN PROJECT

교량 점검 업무 지원 시스템

드론 촬영 자료와 점검 정보를 체계적으로 다루기 위한 웹 기반 업무 시스템입니다. 교량 관리, 점검 관리, 유지보수 관리, 기업 관리·검수 등 주요 기능의 흐름을 연결하는 데 초점을 맞췄습니다.

주요 구성

  • 교량 기본 정보와 점검 대상 관리
  • 현장 점검 기록 및 첨부 자료 관리
  • 유지보수와 기업·검수 업무 연계
  • Spring Boot 기반 API와 웹 프론트엔드 구성
02 / EXPERIMENT

EPUB 웹 뷰어

브라우저에서 EPUB 파일을 표시하는 인터페이스를 실험하는 개인 개발 프로젝트입니다. 라이브러리 로딩과 파일 열기 과정을 검토하고, 장기적인 확장 가능성을 탐색했습니다.

탐색한 주제

  • EPUB 파일 읽기 및 콘텐츠 렌더링
  • JavaScript 라이브러리 연동
  • Electron 데스크톱 앱 확장 가능성
  • 구조 분리와 유지보수성 개선
